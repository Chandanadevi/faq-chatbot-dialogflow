FAQ Chatbot — Dialogflow CX
A conversational FAQ chatbot built using Google Dialogflow CX on Google Cloud Platform (GCP). The bot answers common business questions instantly without any human intervention.

🤖 What it does
This virtual agent handles the following customer queries:

Working Hours — When are you open?
Location — Where is your office?
Contact — How can I reach you?
Services — What do you offer?
Pricing — How much does it cost?
Fallback — Handles unknown questions gracefully

🚀 How to run

Go to Dialogflow CX Console
Create a new agent
Import the agent ZIP from the agent/ folder
Click Test Agent and start chatting!


💬 Sample Conversations
User: When are you open?
Bot:  We are open Monday to Saturday, 9 AM to 6 PM IST.

User: Where is your office?
Bot:  We are located at Hitech City, Hyderabad, Telangana - 500081.

User: How much does it cost?
Bot:  Our pricing depends on project scope. Contact us for a custom quote.
